# 星航生存流程（0.2.0-dev）

本页讲普通玩家在生存模式里怎么玩，全程不需要管理员命令。飞船物理由 Valkyrien Skies 2.4.11 提供，必须安装 VS 和 Kotlin for Forge。

## 一图看懂

```text
主世界                                 勘探月球
──────                                 ────────
合成矢量驱动核心 ─┐
合成船体标尺 ─────┼─► 标出两个对角 → 右键核心扫描 → 再右键装配
                  │
煤 / 木头 / 燃料 ─┴─► 给核心充能 → /starbridge pilot → L 起航
                                        │
合成星图 + 供氧面罩 + 氧气罐 ───────────┤ 爬升到 Y 250
                                        ▼
                                   J 星跃（整船带人）──► 月球上空 Y 170，飞船停泊
                                                         │ L 起航，降落
                                                         ▼
                                          开采星辉矿石 → 星辉晶
                                          挑战遗迹守卫 → 勘探核心 + 星辉晶
                                                         │
                         星辉燃料电池、扩容模块、推进模块、遗迹节能矩阵
                                                         │
                                         爬升到 Y 150 → J 星跃回出发地上空
```

## 1. 造船

| 物品 | 配方 | 说明 |
| --- | --- | --- |
| 矢量驱动核心 | `IRI / DCD / IRI`，I=铁锭 R=红石 D=钻石 C=比较器 | 放置者成为船主。现在可以用石镐以上挖下，会保留能量和已装模块 |
| 船体标尺 | 斜放 2 个铜锭，右上角放 1 个紫水晶碎片 | 右键方块设角点 A，潜行右键设角点 B，右键自己的核心开始扫描，再右键一次确认装配 |

1. 搭好船体，把核心放在里面。
2. 用船体标尺标出包住整艘船的两个对角。
3. 右键核心：开始扫描。扫描完成后聊天栏会报告方块数。
4. 确认无误后再右键核心：写入备份并装配。新船处于**停泊**状态，不会掉下去。

仍可使用 `/starbridge_assemble scan|confirm|cancel|status` 命令，规则见 `docs/assembly.md`。

## 2. 能源

右键核心可以充能：

- **熔炉燃料**：每单位燃烧时间 100 FE，一块煤 160,000 FE，一块煤炭块 1,600,000 FE。**潜行右键会把整组燃料放进去**，直到装满。
- **星辉燃料电池**：每个 1,000,000 FE。
- 也可以用任意 FE 管道从侧面输入，每 tick 上限 200,000 FE。

核心基础容量 2,000,000 FE。

能耗（每 tick）= (4 + 质量 kg × 推力加速度 / 100,000) × 节能系数。旧版本每 tick 重复预付 250 毫秒租期，实际收了约 5 倍的钱。现在只按新增的时间付费，第一次起航时仍会预付完整租期，服务器卡顿时也不会出现白给的推力。

## 3. 驾驶

右键核心选中它，然后输入 `/starbridge pilot` 打开驾驶台。

| 按键 | 作用 |
| --- | --- |
| W A S D | 按视角方向平移 |
| Space / Shift | 上升 / 下降 |
| **Q / E** | **左转 / 右转（新增）** |
| L | 起航（解除停泊） |
| H | 原地悬停 |
| X | 制动 |
| J | 星跃 |
| 右键拖动 | 转动视角 |
| Esc | 离开（飞船自动悬停） |

驱动工作时，核心会持续施加扭矩，让飞船保持水平：被撞歪会自己回正，松开 Q/E 后转动会停下。驾驶台显示航速、模式、航向罗盘、倾斜角、能量、坐标和星跃状态。

航点自动导航仍可使用：`/starbridge navigate x y z`。它不会避开地形，航线上不能有障碍。

## 4. 星跃：整船去月球再回来

**星图**：地图 + 指南针 + 末影珍珠 + 钻石，无序合成。

星跃条件：

1. 背包里有星图（不会消耗）。
2. 飞船已起航（不是停泊状态）。
3. 高度：主世界 **Y ≥ 250**，月球 **Y ≥ 150**。
4. 能量 ≥ 250,000 FE + 每 40 kg 船重 1 FE，再乘节能系数。驾驶台会实时显示还差什么。

满足条件后，在驾驶台按 **J**，或手持星图右键核心。整艘船，包括方块、箱子和机器，会通过 VS 的传送接口移到另一个维度。船体范围内的玩家会被一起带走，并获得 20 秒缓降。

- 去月球：到达前哨西边 48 格、Y 170 的上空。
- 回主世界：回到这艘船出发时的 X/Z 上空 Y 270。没有记录时，回到世界出生点上空。
- 到达后飞船处于**停泊**状态。重新打开驾驶台，按 L 起航后再降落。

## 5. 月球生存

- 重力是主世界的 1/4，摔落伤害也按 1/4 计算。飞船悬停也更省电，因为 VS 月球重力是 2.5 m/s²。
- 船外是真空：要戴**供氧面罩**，并用**氧气罐**补充个人储氧。
- **舰船生命维持（新增）**：核心有电时，站在船体范围内的玩家可以自由呼吸，储氧也会回满。每人每秒消耗 20 FE。
- 前哨信标 7 格内同样供氧。

### 星辉矿石

星辉矿石生成在月球凝灰岩里，Y 4–72，越靠中间越多，会发出微光。需要铁镐或更好的镐，掉落 1–2 颗星辉晶，可用时运加成；精准采集可以挖下矿石本身。

### 遗迹守卫

遗迹在前哨以东 128 格。右键中央的磁石唤醒守卫。

- **重力脉冲（新增）**：守卫会周期性蓄力。听到信标启动声并看到紫色粒子后，约 1 秒内会爆发，把 7 格内的玩家掀飞，造成伤害和缓慢效果。拉开距离就能躲开。
- 生命低于 55%：召唤两名哨兵。
- 生命低于 30%：**过载（新增）**，获得抗性，脉冲加快，再召唤两名哨兵。
- 击败后掉落 4–6 颗星辉晶。每位玩家可以在磁石处领取一个勘探核心。

## 6. 飞船升级

手持模块右键自己的核心即可安装。模块存在核心里，挖下核心也不会丢。

| 模块 | 配方 | 效果 | 上限 |
| --- | --- | --- | --- |
| 扩容模块 | `GRG / XBX / GRG`，G=金锭 R=红石 X=星辉晶 B=红石块 | 储能 +2,000,000 FE | 4 个（共 10,000,000 FE） |
| 推进模块 | `IXI / GPG / IXI`，I=铁锭 X=星辉晶 G=火药 P=活塞 | 手动推力、巡航速度和加速度各 +50% | 2 个 |
| 遗迹节能矩阵 | `XGX / GSG / XGX`，X=星辉晶 G=金锭 S=勘探核心 | 飞行与星跃能耗 -20% | 2 个 |
| 星辉燃料电池 | `RCR / CXC / RCR`，R=红石 C=煤或木炭 X=星辉晶，产出 2 个 | 每个 +1,000,000 FE | — |

## 7. 进度

星航 → 规划航线 → 寂静边疆 → 石中月光 / 沉默档案馆 → 封存的效率

## 已知限制

- 星跃使用 VS 2.4.11 的 `teleportShip`，即带目标维度的 `/vs teleport`。GameTest 已在真实 VS 下验证：整船连同核心（ID、模块、能量）能到达月球。**带着真人玩家星跃、驾驶台 Q/E 转向和自动扶正还没有在客户端里实际飞过**，请先在测试存档里试。
- 只有玩家会被一起传送；船上的生物、掉落物和盔甲架不会跟着走。
- 生命维持只看船体包围盒，不检查船舱是否密封。
- 姿态稳定只处理横滚、俯仰和偏航速率，不做自动对准航向。
