# 远征战役

1. 在主世界制作并带上采样管。到勘测月球后，用采样管右击方解石或凝灰岩，各取两份再返航。安装 Unbound 时，目标是它的月球，月壤或月岩同样能采样。两份样本也可以换成上游的撞击玻璃或星航月球宝库掉落的勘探核心。
2. 用指南针、纸、两份样本和两枚紫水晶碎片制成月面校准星图。晶体也接受 Unbound 的月长石。在主世界手持星图右键，驾驶员就能从导航台选择火星或小行星带。其他船员可以传阅同一张星图，每位驾驶员的航图记录独立保存。联动模式前往火星还需要完成 Unbound 的火星观测。
3. 火星考古队到达时会收到刻石坐标。挖掉遗迹中心的红沙，用采样管右击下面的刻石取得拓片。小行星带打捞队则可用采样管读取残骸中心的切制铜记录仪。两份拓片、两份记录仪或各一份都能配合月面校准星图、纸和青金石制成深空星图。带回主世界右键后即解锁中继锚点。
4. 将调度终端运到深空锚点，放在报告位置的錾制基石上。手持货物右击终端，可分批交付 3 个中继天线组件、32 个铜锭和 8 个红石块。所有玩家共享工程进度，提交时只取尚缺的数量。最后一批材料到位时，全服会收到中继站开通的通知。
5. 中继站按顺序发出补给、测绘和救援委托。将一组 16 个面包、一份火星遗迹拓片分别交给调度台，随后带采样管去残骸中心以东四格的蓝冰逃生舱，接回一枚载人的救生舱。委托分别支付 4、4、6 颗绿宝石，最后一次交付后重新开放补给任务。

火星遗迹优先选择 X 0、Z 32 附近的地表。小行星带残骸和深空锚点位于各自维度的 X 0、Y 112、Z 32 附近。建设前会检查是否有足够的空气方块，并可选用邻近空地。请按到站提示的实际坐标降落，先准备好返程能源和可返回船舱的通道。
