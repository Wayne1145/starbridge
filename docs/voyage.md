# 航图、船舱与泊位

星航 0.2 使用 Java 17 和 Minecraft Forge 1.20.1-47.4.28。要驾驶方块船，请同时安装 Valkyrien Skies 2.4.11 与 Kotlin for Forge 4.11.0。可选的 UnBound 0.16.1 需要 GeckoLib 4.8.4，并应安装在服务器与每个客户端。作者通过 CurseForge 提供原模组，星航发布包只包含自己的代码与资源。

1. 主世界晴夜举起望远镜，沿无阻挡视线对准月亮约 1.5 秒，可记录月球航线。装有 UnBound 时，用它的天文望远镜完成星辰日志中的月球发现。
2. 合成航图终端、飞行核心和氧气罐。在飞船的封闭舱室内安装供氧器，拿氧气罐右键充气。每罐可供一人呼吸 120 秒。每个供氧器负责与其连通、至多 768 个空气方块的小舱室。使用完整方块和关闭的舱门密封；外门打开就会泄压。大型船可按舱室布置多台供氧器。舱外活动另需个人装备，UnBound 世界沿用它的宇航服。
3. 按 [装配流程](assembly.md) 将结构变为一艘实体船。船主向核心输入 FE 或用熔炉燃料右键充能。站在甲板上，用航图终端右击核心，选择目的地并确认。也可用 `/starbridge chart` 打开图，或用 `/starbridge voyage moon` 选择同一航线。终端显示去程费用和要求留下的返程能源。驾驶室使用 `/starbridge pilot`，开启本地动力用 `/starbridge launch`。
4. 航程会将船和在船上有落脚点的在线船员送往目的地的安全泊位。请在出发时站在甲板上并下坐骑。母港记住从主世界启程时的实际船位。抵达后可手动飞行，或保持停泊并下船探索。准备梯子或落地平台，深空和小行星带泊位附近有虚空。
5. 参阅 [战役路线](campaign.md) 了解采样、火星遗迹、残骸打捞、中继站建设和后续委托。已配对的游戏电脑可调用 `getChart()` 和 `setCourse("home")`，外部 MCP 客户端可调用 `get_star_chart` 和 `set_course`。自动航程要求船主在线并在甲板上，人工驾驶拥有优先权。

每一段采用两地间的航程切换，星球附近的手动航行采用 VS 物理。多人同时在线的性能、整舰连续飞越大气层、300 格船和外部机器模组应分别对照实测结果。UnBound 现有的小艇可到同一个星球活动，移动母舰上的实体舰载机锁定和动态对接目前仍需后续开发。
