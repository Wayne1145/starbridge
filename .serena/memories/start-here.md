# Starbridge 项目交接

使用这份记忆时，先在仓库根读 AGENTS.md，再核对当前 Git 分支和 HEAD。源码、运行日志和版本化实测报告决定功能状态。mem:code-map 记录开发入口，mem:verification 记录实测边界。所有下述文件路径均相对仓库根目录。

玩家目标是在 Forge 1.20.1 生存世界自己搭建多层方块飞船，在航行中走动、操作机器，并在手动驾驶和自动驾驶间切换。单人、局域网和长期独立服都在范围内。船长 100–300 格指船首到船尾的长度。长期服目标是 10–30 个同时在线的玩家。

保留 Galacticraft、ExtraPlanets、GalaxySpace 的探索与解锁节奏，借鉴 Advanced Rocketry 的自建船。可选 UnBound 通过原作的维度、个人星辰日志和供氧接口联动。具体版本在 gradle.properties、build.gradle 和 docs/compatibility.md。第三方模组由玩家从正式渠道安装。源码、世界、美术和预制小艇按上游的授权处理。

第一季从望远镜观月、建船和登月采样开始。返航校准星图后可以去火星考古或小行星打捞，结局是一起建成深空中继站，之后可领取反复执行的委托。母舰用于带人、机器和大宗货物，原作小艇用于侦察。近距离物理飞行与两端泊位之间的跨维航程各有验收条件。计划和玩法取舍在 docs/unbound-roadmap.md，当前配方和进度在 docs/campaign.md。

2026-11-21 的远征工作在 codex/expedition-campaign、PR #1，远端与合并状态随开发变化。接手时优先查实测报告，先验证真实客户端在推力航行的多层甲板上行走、操作箱子和机器，再测掉线、服务端重启、200/300 格船和多人负载。新生存档从望远镜到返程也需独立验收。继续实机测试时使用项目独立存档和后台桌面或测试机，让用户继续使用自己的鼠标键盘。
