# Starbridge 项目交接

从 AGENTS.md 和 docs/integration-plan.md 开始，核对当前分支、HEAD 与最新用户指示。2026-11-21 玩家已纠正融合方向，当前路线以这份融合大纲为准。mem:code-map 描述现有代码入口，mem:verification 只记录已经做过的测试。

Starbridge 做联动附属。目标是用 Advanced Rocketry 的发射台、塔架、组装机、加注与发射流程搭自己的多方块飞船，飞往 Galacticraft、ExtraPlanets、GalaxySpace 自己提供的世界，游玩对应上游的地表、地牢、Boss、掉落与升级。缺少兼容上游时把缺口写清，只有原内容提供方或保留原内容的可发布移植实际运行才算接入。保持 Forge 1.20.1。用户要先看大纲，独立移植缺失上游属于需商定的工作范围。

图形界面是全项目的玩家验收条件。普通生存玩家关闭作弊、没有管理员权限，也能在游戏内找到下一步，用原组装机、可点选的星图、驾驶席、着陆仪和可改绑按键走完造船、检查、加注、升空、手动与自动驾驶、着陆、返航和接管。界面要能看出错误位置或原因及如何纠正。验收整趟任务不能输入聊天命令或查控制台。命令供管理员诊断和开发测试。CC:Tweaked 和由船主授权的 MCP/AI 是可选操控方式。

太空自由驾驶参考 UnBound 的第三人称体验。设想让方块船舱留在固定位置正常运行，驾驶员看到自己搭的船体外观，服务器记录共享太空中的位置、朝向与速度，船员在多层舱内走动和使用机器。接近真实行星地表再切入 Valkyrien Skies 物理，起飞按相反顺序交接。同一船、船员相对位置、机器、燃料与货物要跨阶段保留。单人、局域网和 10–30 人长期专服都要实测。100、200、300 格是船长，分档记录船宽高、实际方块、机器数与并发。

首选验证 Retrofit 0.6.2-beta，把 1.7.10 原包加载到 Forge 1.20.1 宿主。该作者报告 Galacticraft 3.0.12 Core 与 Planets 的原月球、火星、小行星带、空间站和原火箭已运行。此路线的原地牢、钥匙、箱子、两款扩展、高级火箭与 LibVulpes、多人和 VS 组合均待本项目实测。分版核对 1.7.10 与 1.12.2 的内容差异。UnBound 0.16.1 的公开方法可以登记外部维度，能否驾驶自建船需测。原包接入在前，另行移植的范围与授权排在其后。首个可玩验收是用高级火箭原流程完成一次小船载人登月，到 Galacticraft 的月球打原地牢 Boss、拿原奖励再乘原船回家。之后才逐个验收两个扩展、大船、多人与电脑控制。

0.2 旧原型和历史 PR #1 的战役在 docs/unbound-roadmap.md 与 docs/campaign.md。旧测试的 52 方块双人 UnBound 月球往返、100 格短航点、300 格试飞超时，记录在 docs/test-report.md 和 docs/expedition-verification.json。它们用于复用测试方法。新融合路线尚需独立验证。实机试验用独立存档和后台桌面或测试机，让用户继续使用自己的鼠标键盘。
