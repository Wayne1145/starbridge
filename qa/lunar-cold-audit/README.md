# 原月面地牢和扩展奖励的冷启动验收

2026-11-22 使用 Forge 47.4.28、Java 17 和公开构建 `a90ea7c` 的完整整合包。四份独立世界副本分别经过专服启动、目标区块就绪确认、保存和停机。全程零玩家在线。自然远征的原存档用于读取此前真正走过的地形、游戏视距和观察记录。读取所得的位置只存在于开发检查进程及本地隔离副本中。[汇总与存档哈希](verification.json)

双人战斗存档和自然远征存档使用不同种子。两个世界都保有通向天空的原地牢竖井。从各自的井底出发，都可沿现有方块走到原首领房和宝箱旁。核对采用两格净空、落脚支撑、至多一格上行和三格下降。入口周边的普通步行检验未找到可以从上沿一路走到井底的缓坡。玩家在月球重力下如何安全下降仍需操作验收。

自然远征的三份末段检查点共有 262 个不同实走位置。在当时六区块的设置下，有记录的位置进入了入口所在区块的追踪范围。已有 83 份视角记录，其中 82 份带准星方块字段，没有一份记录确认原地牢砖。最近那次工程师确实走进了天然洞穴。在开挖前的停服位置开始扫描，洞穴内连通的 116 个可站位置和 230 个有两格净空的有顶位置均未接到砖室。扫描覆盖该连通部分，未触及缺失区块或搜索边界。

自然远征档的一段原通道有蛛网。将蛛网视为可缓慢穿过，就能从井底抵达两间房。相同地形中误将蛛网视为墙，两条路径都会被错判为不通。另一个容易误判的情况来自尚未完成生成的区块。原远征存档里已经有首领刷怪器方块，完整专服加载后才写入原进化骷髅刷怪器数据。结果文件同时保留冷启动前后的原始状态。

| 已打开的原宝箱 | 冷启动后 | 与启动前对照 |
| --- | --- | --- |
| 双人原月球地牢，一级 | 11 个非空槽，12 件物品 | 锁状态、每个物品的原 ID、数量与附加数据均一致 |
| GalaxySpace 谷神星，四级 | 14 个非空槽，25 件物品 | 全部原库存一致 |
| ExtraPlanets 金星，四级 | 14 个非空槽，17 件物品 | 全部原库存一致 |

另有尚未开启的宝箱在两次存档中都保持上锁。此前的战斗与开箱有独立运行记录；本项核对其冷启动保存结果。

从仓库根运行以下命令。`rehearsal-b` 须替换为尚未使用的目录名。启动器只使用本机回环端口 26944，每次启动一份世界的副本。开发用区块加载命令和现场日志保留在忽略提交的 `.local` 目录。`verify.py` 从实际存档重算几何、原箱物品、玩家可见性证据和哈希，输出不包含种子、位置或方向。

```powershell
py -3.12 -B qa/lunar-cold-audit/cold_server.py rehearsal-b paired natural ceres venus
py -3.12 -B qa/lunar-cold-audit/verify.py qa/lunar-cold-audit/.local/rehearsal-b qa/lunar-cold-audit/.local/recheck.json
```
