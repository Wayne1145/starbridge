# 两人空背包开始同一趟远征

[GitHub 托管测试](../../../.github/workflows/survival-pair.yml)给船长和工程师分别启动一个渲染客户端，连入同一台 Forge 47.4.28 专服。两端都采用完整原包组合。服务端从普通难度的新世界开始，每个角色入服时分别记录空背包、生存模式、操作员权限和作弊设置。观察附属在两人到齐后才发出首段操作。

两人各自砍白桦木、做木板和工作台、在工台上合成木镐，再挖十四块圆石。Baritone 在测试客户端负责步行与采掘。工作台、物品与合成产物来自普通游戏操作。完成两人的订单后，测试先退出客户端，再正常停服。停服存档里的两把木镐和两份圆石均须与两人的操作记录一致。

`original-survival-pair-<运行编号>-<尝试次数>` 产物包含这次云端生成的世界、两个角色的订单和游标、装载清单以及观测结果。上传的存档来自这次托管测试。后续远征从保存的世界和角色进度接续，读取 `pair-result.json` 的 `completed` 可以区分完成首段和提前停止。完整登月、自然找到地牢及带回奖励仍需在同档中完成。

手动运行时，`previous_run` 指定本仓库先前的双人远征编号。工作流校验归档与世界摘要，恢复两个角色和已执行的订单。在 `materials` 阶段，船长采铁、取水、收集沙砾，制作 16 块原高级火箭混凝土。工程师收集羊毛，制作一个原座椅。进度从各自的游标继续。两种原产物都需在关服后的对应背包中读到。

首段实测运行 `44992119186` 的两个普通玩家各自合成工作台和木镐，均以满血退出。两个原始游标都是 10。仓库保留了这次 GitHub 机器生成的[原始产物](../../../docs/evidence/original-survival-pair/44992119186-1.zip)。在仓库根用 `python -B qa/survival-expedition/hosted-pair/replay.py docs/evidence/original-survival-pair/44992119186-1.zip` 可离线核对分玩家的合成事件、完整订单、统计和背包。材料试验 `44993373934` 从这份世界恢复。服务端先记录两人重新登录时的背包，再从各自保存的游标继续。其他运行的产物也可用此工具复核，`--previous` 接受上一段的解压目录或原始归档。

验收一段从托管存档继续的远征时，提供 `--previous` 指向直接上一段的产物。回放会核对世界摘要、两人的游标和已执行订单，再把上一段关服存档中已累积的合成统计与当前段的新合成事件合并核对。工作流自动传入它下载的上一段产物。


船长和工程师在 `44993373934` 分别推进到第 35 和第 14 步。船长熔出铁锭并做成桶，随后被骷髅射杀。工程师带着工台停在树上。两人正常退出后的[完整存档](../../../docs/evidence/original-survival-pair/44993373934-1.zip)已按 GitHub 原始摘要冻结。`yard` 段使用相同角色、背包、世界和已经执行的订单。船长重制工具与盾牌，工程师下树回到实际存在的营地工台。后续两人自行收集混凝土、墨囊、黄染料以及羊毛，在营地铺九块原发射台并放置原座椅。存档审计核对原方块的十个具体位置。

同一 PR 的后续试验会优先恢复上一段留下的正常停服世界。新的小型续档凭据记下两名角色的游标及世界摘要。程序恢复后重新核对这两个值。`completed` 表示两人已完成这一阶段的所有订单。运行未达到阶段目标时，存档仍可在同一旅程继续。[材料阶段原始观测](../../../docs/hosted-survival-yard-verification.json)

手动运行把 `previous_run` 设为 `surface-camp` 时，会从另一份已有完整空背包起点的双人远征接续。归档来自 `20261122-104205-3e9f` 正常停服后的原存档。先保存两名玩家的已执行操作，再从 295 和 680 两个游标接续。工程师等待之前种的甘蔗生长，取自己先前存下的指南针和玻璃板，做终端并实际打开安装检查和两种造船图。该次继续保留压板器、原锡块和其他已采材料。

续做终端时把 `previous_run` 设为这条原营地远征的上一运行编号，阶段选 `terminal`。关服产物保留工程师用自制终端打开安装检查、俯视图和侧视图的客户端记录与截图。停服时的终端、合成统计和服务端取件事件另外核对。

原营地运行 `45033038360` 已做成并读过航图终端。选 `surface-yard` 并以此编号为 `previous_run`，船长用随身的水桶和新挖的材料制作原混凝土与发射台，工程师带终端去营地取剪刀，剪羊毛并手摆原座椅配方。回放仍要求从落盘的营地区块读到九块原发射台和一张原座椅。

在关服区块确认中央原座椅已经装好后，用该次运行编号和 `surface-workshop` 阶段续档。船长取用原营地富余圆石，重制工具、采矿、熔出铁锭并做出倒模用的两个桶。工程师保留终端，在另一张工作台做石斧。验证会检查旧发射台和座椅仍在，两人的存档持有工具和铁料。压板器、锡块和拉杆继续保存在营地。

`surface-cast` 从车间备料的关服档继续。船长在木营地以东用实际圆石封好倒模坑，从原档已经生成的洞道取一桶熔岩，再用另一桶水原地铸造黑曜石。工程师带原终端回到营地。关服核对原发射台、座椅、黑曜石及周围五块圆石。原压板器的安装和出料是后续步骤。

`surface-press` 接在黑曜石倒模之后。工程师从原营地箱取小型压板器、原锡块和拉杆，在黑曜石上从下往上安装，通电后收集原锡板。关服回放核对输入格已经空出、压板器仍在，以及工程师拿到四块正确原物品变种的锡板。
