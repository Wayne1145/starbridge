# 甘蔗自然生长与首台航图终端

这一段从工程师种好两株甘蔗时的备料进度开始。`checkpoint.json` 的七个整数记录两株甘蔗的年龄、身上的铁锭和红石、箱中的指南针和玻璃板，以及原档的随机刻速度。两株作物上方均为空气，角色和营地箱都没有甘蔗、纸或航图终端。

原始资料来自本项目独立测试实例 `run-survival-expedition-a1` 在 2026 年 11 月 22 日 10:50:17（上海）关闭时的[存档记录](../survival-tin-verification.json)。开发机可在仓库根运行 `python -B qa/survival-expedition/hosted-garden/read_checkpoint.py` 读回这七个数。脚本先核对原件哈希，仅输出相应的整数。

GitHub 托管的客户端会创建独立的生存世界，关闭作弊。新角色空背包加入，夹具用上述数值布置一个便于观察的屋顶菜园。工程师此前采矿、种植、建营地的过程有各自的本地存档记录。云端从布置好的菜园开始计时，在默认随机刻下等待首次出现新的上层甘蔗。服务器记录这次自然生长、玩家收割两株作物、工作台产出三张纸和一台终端。客户端从营地箱取料，在工作台逐格摆料，使用自制终端切换俯视和侧视，再放回箱中。结束后从已关闭的云端世界核对箱中恰好一台终端及剩余材料。

工作流发布截图、按顺序记录的操作、JAR 哈希和脱敏的生长及存档结果。本地存档和云端存档均留在各自的运行环境。[远程工作流](../../../.github/workflows/remote-gui.yml) · [可复核的七个输入](checkpoint.json)
