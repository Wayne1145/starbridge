# 月面地形剖面与徒步

在航图终端的「地表勘察」点一个地形格，可以看到经过实测地表的东西和南北两条剖面。每条线各跨 25 格，两图采用相同高度比例。金色标记对准所选格中测得的低点。若该格采样到露天月面砖，紫色格标出表面纹理，剖面中心对准这处露砖。用 Tab 聚焦「地形剖面」后，也能用方向键移动图上选框，再按回车打开该处。坑沿高差取四边中第三高的一边与该点的差，底宽统计图内与该点高度相差至多两个上行台阶的连续区段。尚未加载的地表保留空白。

两向都窄且深时，图中会建议走到坑沿观察露出的岩壁。单向细长多见于岩沟。玩家在坑沿转动视角瞄准岩壁后，点「坑沿观察」可辨认准星首先看到的原方块。发现砖纹与通道后可以回勘察图记录脚下的位置。

[Lunar field survey](../../.github/workflows/lunar-field.yml) 用 GitHub 托管 Linux 的中文客户端，在已有 QA 远征相同种子的原 Galacticraft 月球上生成新存档。出发甲板采用旧终端中工程师标记的飞船水平位置。玩家只操作当前这次的终端、地图、视角和移动键。首轮测试预置九块铁甲板。接续任务用一艘已登记母港的测试船出发，船上预置舰桥、标记货物和能源。角色携带配对终端、普通盔甲、铁剑、铁镐、食物、缓降药水、梯子、搭路方块以及原版面罩、供氧组件、氧气瓶。

远程端先确认关闭作弊，保存飞船标记，再从图中选择实际显示的洼地或陡降格。玩家以 25 格剖面比较各处的地形，沿安全可见的地面徒步，到坑沿转动视角辨岩。确认露出的原地牢砖后尝试喝下缓降药水并靠近。地牢交互需要服务端收到对可触及原砖的右键事件。击败原首领、拾取原钥匙各自另有实际事件记录。用完这段行程后正常停服，证据里保存角色背包、健康、位置、地图标记、两组剖面采样和实际走过的路。

工作流用两个步骤分别验收徒步和原地牢交互。`field-audit.json` 记录停服读档，`field-progress.json` 保存玩家看过的地形，`field-result.json` 记录本次达到的位置。若原地牢交互步骤未通过，其余真实的观察仍保留在该次运行的 `lunar-field-walk-…` 产物里。

首轮运行 `44991338272` 记录九组剖面，得到开阔地、宽坑、窄井和准星辨认天然月石的四张截图。角色随后卡在天然洼地。最后 25 次采样的平面坐标相同，服务端没有收到原地牢砖交互。[首轮记录](../../docs/hosted-lunar-field-verification.json) · [原始产物](../../docs/evidence/lunar-field/44991338272-1.zip)

后续徒步使用勘察图中的粗略等高线选绕行方向，放大到每格一方块后沿相邻步级行走，遇阻会另选路线。每次坑沿观察记录实际脚下位置、剖面中心与选中的坑沿。复核按平面位移判断角色是否离开甲板，并检查观察时离坑沿和剖面中心的距离。

原月球远征的归航从拾取原首领掉落的钥匙开始。角色按已有脚印回到竖井，使用随身的方块出井，再按终端中亲自留下的船位走回舰桥。原专属首领击杀、钥匙拾取、带钥匙登上出发船与同船落在母港各有独立服务端事件。停服后从主世界区块读取舰桥、原火箭、船长、收费收据和出发货物，再核对背包里的钥匙。

在仓库根运行 `python -B qa/lunar-field/replay.py docs/evidence/lunar-field/44991338272-1.zip`，可以离线复核原始高度、渲染截图、存档和事件。后续运行可替换为相应的 GitHub 原始产物。

每次正常停服后，工作流另存 `lunar-world-…` 产物。里面有这个独立试验存档和本趟实际事件，哈希由 `field-audit.json` 记录。后续可以从本次角色的位置继续行程。
