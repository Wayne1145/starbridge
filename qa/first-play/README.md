# 首次游玩观察

给首次接触星航的玩家看[试玩目标](player.md)。观察员保留下面的入口与核对项目，由玩家在有独立输入设备的机器上亲手操作。单人、局域网和专服分别记录。自动运行的远征以及已熟悉星航的开发者回放各有自己的记录。等待首次真人观测。

准备 Forge 47.4.28、Java 17 和同一份星航开发包。记录提交、主 JAR 的 SHA-256、已装原包、客户端语言和原有模组经验。用新世界、普通生存身份、空 OP 名单和关闭作弊开始。另起预置场景时，写下预置的材料、机器、飞船、落点或地牢知识，并保留原世界继续长程试玩。使用仓库中的[安装说明](../../docs/install-original.md)准备两端。

| 观察时机 | 观察员记录的具体行为 |
| --- | --- |
| 安装检查 | 在尚未进世界时，玩家能否找到缺少的组件、准确文件名及放置目录。补齐组件后读数有何变化。 |
| 第一次造船 | 第一次工作台之后从哪里发现航图终端。能否用图中物品辨认材料、逐层搭建原船坞、看出组装机有没有电。 |
| 扫描和修补 | 玩家依据什么标记找到楼层和方块。补块或更换部件后如何确认问题消失。观察员预置故障时单列。 |
| 舰桥与船员 | 船长怎样选月球、加注、登船、启用巡航并接管。另一名玩家怎样找到船员仪表、认出控制方并回到机器。记录实际键位或改绑。 |
| 着陆与出舱 | 怎样判断泊位可用、遇阻时是否保留原航线并能改选。怎样配氧、标记船位、在原月面寻找地牢。 |
| 原奖励与返航 | 记录原首领、钥匙、宝箱内取出的物品和船上货位。正常退出后复核同一世界、同一艘船及回港货物。 |

每个受阻步骤写一行 `场景　玩家想做什么　第一次打开的界面或按键　看到的反馈　下一步动作　场外提示　结果`。如果给过提示，逐字记下第一条以及发生时间。一次试验可以同时包含自主完成、提示后完成和仍受阻的步骤。报告按步骤给出结论。长程试玩可保留停服存档摘要与下一次恢复使用的世界标识。有截图或手写记录时，只需保存能辨认操作和反馈的部分。
